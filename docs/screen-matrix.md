# Screen coverage

The executable screen inventory lives in [the performance lab](perf-lab.md).
It derives routes, roles, states, and controls from the current source.
Generated coverage matrices belong in the selected external evidence directory.
Historical captures do not prove current coverage or physical iPhone behavior.

See [architecture](architecture.md) for screen data ownership, [data flow](data-flow.md) for requests, and [PWA behavior](pwa-live-data.md) for recovery.
